# Customer Ticket API — Integrated DevOps / CI-CD Project

This repository contains an end-to-end DevOps CI/CD pipeline for a Python Flask-based Customer Ticket API using Git, GitHub, Jenkins, Docker, and Kubernetes (Minikube).
